⚙️ Cài đặt kết nối
Nhập URL Google Apps Script Web App để kết nối với Google Sheets lưu dữ liệu kho.
1
Mở script.google.com → tạo project mới (gắn với 1 Google Sheet trống)
2
Dán nội dung file Code.gs vào → Save
3
Deploy → New deployment → Web App
Execute as: Me · Who has access: Anyone
4
Copy URL .../exec và dán bên dưới
